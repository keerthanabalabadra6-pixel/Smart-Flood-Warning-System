# AI-Powered Smart Flood Warning System — AI-Powered Smart Flood Warning System

A Flask web application demonstrating a Random Forest classifier for educational flood-risk prediction.

> **Safety and research note:** The included dataset is synthetic demonstration data. It is only intended to test the software workflow. It is not a verified hydrological dataset, the model is not validated for real-world forecasting, and this application is not an official warning service. Do not use it for emergency decisions or claim its synthetic-data accuracy as real-world performance.

## Features
- Home dashboard and project information
- Environmental input/monitoring overview
- Random Forest flood-risk prediction
- Risk messages and general safety guidance
- Session-based prediction history and Plotly chart
- Responsive HTML/CSS/JavaScript interface

## 1. Run locally

Use Python 3.10 or newer. Open a terminal in this folder and run:

```bash
python -m venv .venv
```

Activate it:

- Windows: `.venv\\Scripts\\activate`
- macOS/Linux: `source .venv/bin/activate`

Install dependencies and create/train the demonstration model:

```bash
pip install -r requirements.txt
python train_model.py --make-demo-data
```

Start the website:

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## 2. Replace the demo dataset

Replace `data/flood_dataset.csv` with a suitable dataset whose columns match exactly:

- `rainfall_mm`
- `water_level_m`
- `temperature_c`
- `humidity_pct`
- `soil_moisture_pct`
- `recent_flood_history` (0 or 1)
- `flood_risk` (`Low`, `Moderate`, `High`, or `Critical`)

The values and labels must be sourced and documented. Check units, location, time period, missing values, label definitions, class balance and possible data leakage. If the source uses different columns or risk labels, carefully adapt the preprocessing and feature mapping rather than relabelling blindly.

Retrain after replacing the CSV:

```bash
python train_model.py
```

The saved model is written to `models/random_forest_model.joblib`.

## 3. Deploy on Render (free plan subject to current limits)

1. Push this entire folder to a GitHub repository.
2. In Render, choose **New + → Web Service** and connect the repository.
3. Select the Free instance type if offered for your account/region.
4. Build command: `pip install -r requirements.txt && python train_model.py --make-demo-data`
5. Start command: `gunicorn app:app`
6. Add an environment variable named `SECRET_KEY` with a long random value.
7. Deploy and open the generated `onrender.com` URL.

**Important:** The build command above recreates the synthetic demonstration dataset and model. For a real dataset, commit the verified CSV and change the build command to `pip install -r requirements.txt && python train_model.py`. Render free services may sleep when idle and have an ephemeral filesystem; session history is temporary and local file changes do not persist across restarts. Do not store sensitive information here.
